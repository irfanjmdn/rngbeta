# Spotify Crate RNG

Standalone Roblox-style track crate RNG spinner and card collector powered by any public Spotify profile.

## How to Run

```bash
# Option 1: Run production server (serves dist/)
python server.py

# Option 2: Run frontend dev server with live reload
cd frontend
npm run dev
```

## Key Files

* `server.py`: Python 3.13 HTTP and Server-Sent Events (SSE) server. Serves `dist/` if present, falling back to `public/`.
* `frontend/src/App.svelte`: Root application coordinator.
* `frontend/src/components/`: Modular Svelte components (`Onboarding`, `Hud`, `Reel`, `WinnerSpotlight`, `Deck`, `BinderModal`, `RatesModal`, `SettingsModal`).
* `frontend/src/lib/audio.js`: Web Audio and sampled mechanical SFX engine.
* `frontend/src/lib/store.js`: Reactive stores for inventory, rolls, audio playback, and telemetry.
* `frontend/src/lib/sse.js`: Server-Sent Events scraper client.
* `dist/`: Production build output directory generated by `npm run build` in `frontend/`.
* `public/`: Legacy fallback static assets and audio files.
* `tests/verify_rng_app.py`: Automated Playwright test suite for desktop and mobile verification.

## Dependencies and Setup

* Python 3.13 (stdlib only).
* Node.js v24+ for building frontend (`cd frontend && npm install && npm run build`).
